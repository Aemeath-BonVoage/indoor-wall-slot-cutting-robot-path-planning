# 路线图

本文只列计划与进行中的工作。已完成的工作按阶段记录在 [项目演进](EVOLUTION.md)，详细数据见各实验报告。

每项工作的完成标准：在 Gazebo / RViz 中实际运行，并留下可复现的命令、原始数据和报告。

## 进行中

### 1. 精对位升级：AprilTag + EKF + 控制器重新设计

**动机**：多站执行中剩下的主要误差是每次运行的常值横向偏差（0.65–2.3 mm），等于起点精对位停下时沿墙方向的残差；对位误差主要由 1 cm 停止判据和 5 mm 死区决定；相机偏航每 1° 约产生 10 mm 横向偏差。当前 5 cm 色块标记只提供一个质心，尺寸小、可观性弱。

- [ ] AprilTag 定位标记：检测与位姿估计，替换色块标记
- [ ] EKF：融合激光墙面拟合、视觉标记位姿与里程计，给出带协方差的底盘位姿估计
- [ ] 对位控制器重新设计，给出稳定性分析；收敛判据改为“误差在容差内且速度趋零”
- [ ] 相机外参标定 / 示教零偏；在 URDF 中加入已知的相机安装误差验证
- [ ] 对位结束时用测得的残差修正墙面参考原点
- [ ] 在 Gazebo 中与当前 PBVS 对比（随机起点、里程计漂移、传感器噪声），出实验报告

### 2. 任务级联合规划：槽线路线与停靠站

**动机**：多条槽目前按顺序逐条规划，先规划的槽可能让后面的槽无解；停靠站在槽线确定之后才划分；宽墙上规范约束会迫使台阶形路线。

- [ ] 联合优化多条槽的路线、停靠站划分与访问顺序，目标为总执行时间
- [ ] 多方案决策：路线弯数过多时给出改走吊顶 / 地面等替代方案
- [ ] 随机墙面生成器扩展，数百面墙的批量基准测试；与逐条规划、第一版规划器等基线对比
- [ ] 停靠站位姿与占用地图的碰撞检查

## 不再计划

| 项目 | 原因 |
|---|---|
| 迁移到 Gazebo Harmonic（`ros_gz`） | 当前仿真配置 v2 已满足实验需要；迁移工作量大，对研究问题没有直接贡献 |
| 与 Theta\* / JPS 等任意角度规划器对比 | 开槽只允许横平竖直的线段，任意角度规划器不是合适的基线；改为与逐条规划、第一版规划器对比 |
| 单独的 Nav2 参数调优 | 导航只负责把底盘送到墙前约 1–2 m 处，精度由精对位保证；当前参数下多站任务的导航段全部成功 |
